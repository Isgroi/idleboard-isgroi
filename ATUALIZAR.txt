ATUALIZAÇÃO DO IDLEBOARD ISGROI — 1.0.8

1. Feche o IdleBoard Isgroi.
2. Extraia o ZIP completo para uma pasta sua. Não execute o programa dentro do ZIP.
3. Abra IdleBoard-Isgroi.exe da pasta extraída.

As sessões e preferências continuam na pasta de dados do Windows, separadas do
programa. Não copie seus cookies, sessões ou credenciais para a pasta do projeto,
para o ZIP ou para o GitHub.

A extensão /hunt for PokeIdle é opcional e não está incluída neste pacote.
O aplicativo e o jogo funcionam sem ela. Para instalar sua própria cópia local,
consulte codigo-fonte\README.md, na seção "Extensão /hunt". Não publique a
extensão nem seu arquivo .crx com o código do IdleBoard.

O modo DEV usa uma pasta de dados separada do aplicativo estável.
