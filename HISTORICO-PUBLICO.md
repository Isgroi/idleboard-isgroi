# Histórico público do IdleBoard Isgroi

Este repositório reúne cópias verificáveis das versões que foram preservadas. As tags `v1.0.0`, `v1.0.1` e `v1.0.3` vêm dos ZIPs originais; `v1.0.5` e `v1.0.6` vêm do histórico Git local. Não há cópias verificadas das versões 1.0.2 e 1.0.4 neste repositório.

As versões históricas foram **sanitizadas para publicação**: os arquivos da extensão de terceiros `/hunt for PokeIdle`, inclusive o `.crx` e o teste do código incorporado, foram omitidos de todos os commits públicos. Os documentos originais de algumas versões ainda mencionam uma extensão incluída; essa afirmação descreve o pacote privado original, **não** esta cópia pública. Nessas tags, a função da extensão pode não estar disponível. Para uso opcional de uma cópia pessoal da extensão, consulte o README da versão atual.

As tags públicas identificam o código do IdleBoard que existia em cada versão, com essa remoção obrigatória. Seus hashes de commit não são os mesmos do histórico privado preservado localmente. Não publique os ZIPs antigos sem inspecioná-los: alguns incluem a extensão.
